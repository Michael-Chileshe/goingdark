# GOINGDARK 🔐

GOINGDARK is a simple, transparent, and educational anonymity toggle for Kali Linux.

It allows you to safely switch between:
- 🔓 Normal / Lab Mode
- 🔐 Tor‑enforced Anonymous Mode

This project is designed for **education, research, and OPSEC learning** — not misuse.

## 🧠 What This Does
- Forces all TCP traffic through Tor
- Prevents DNS leaks
- Blocks traffic if Tor is unavailable
- Allows safe switching between modes
